What this program is

A 4-week, self-paced, text-based Terraform bootcamp: 12 modules and a capstone. You build one Terraform codebase, step by step, and at the end it runs a Terraform Flashcard Quiz you can open and play in your browser. A React page runs on Auto Scaling web servers behind a public load balancer, a Node.js API sits behind an internal one, and your cards and answers live in Amazon RDS for MySQL. It all runs in AWS Singapore (ap-southeast-1), with an off-site backup in Google Cloud Storage and the quiz's theme and logo served from Azure Blob Storage.

The application is provided. Your job is the infrastructure around it, and every resource is created and destroyed by Terraform in your own sandbox accounts, sized to keep cloud spend minimal. Every module has a short lecture, a guided lab with the expected output of each command, a solved practice exercise, and Next steps: small capstone tasks you build yourself, with no solution given.

What you'll learn

Local state first, then S3 remote state with native locking
One Terraform module per resource type, reused
A tiered VPC and a least-privilege security-group chain
Self-healing Auto Scaling groups behind load balancers
RDS MySQL 8.4 with a password nobody ever types
dev and prod workspaces with guards that fail safely
CloudWatch alarms, SNS email alerts and an AWS Budget with early-warning alerts
Multi-cloud: Google Cloud Storage and Azure Blob with CORS

Suggested pace

One module per day or two, about 22 hours of labs in total. M1 and M6 are the longest; budget extra time for them. Don't leave each module's Next steps for Week 4: they're the pieces of your capstone. Prerequisites: Terraform 1.11 or newer, the AWS CLI, and sandbox accounts on AWS, GCP and Azure.

The one rule

Every resource is managed by Terraform, so terraform apply and terraform destroy are the whole lifecycle. Never create anything by hand in a cloud console: Terraform can't see it, destroy won't remove it, and it keeps billing on your account.
